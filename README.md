# RallyRoute

A low-cost wearable system for measuring badminton footwork.

## About the Project

RallyRoute investigates whether a single low-cost, ankle-worn motion sensor can produce repeatable measures of six-point badminton footwork.

The project will explore how raw movement data can be processed using Python to produce simple and interpretable measurements that may be useful to school-level badminton players and coaches.

## Research Question

To what extent can one low-cost, ankle-worn motion sensor produce repeatable measures of six-point badminton footwork for school players and coaches with useful feedback?
